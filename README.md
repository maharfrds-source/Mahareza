## 🚀 Panduan Deployment ke Vercel

1. Push folder ini ke GitHub:
   ```bash
   git init
   git add .
   git commit -m "Deploy Mahareza Firdaus Drafter Portfolio"
   git branch -M main
   git remote add origin https://github.com/USERNAME/portfolio-mahareza.git
   git push -u origin main
   ```
2. Buka [Vercel.com](https://vercel.com/) $\rightarrow$ **Add New Project** $\rightarrow$ Import repository GitHub Anda $\rightarrow$ Klik **Deploy**.
